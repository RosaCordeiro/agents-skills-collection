# Modelo do perfil SoftDesk

Copiar para `~/.claude/softdesk-perfil.md` e preencher com os valores da própria
pessoa. Este arquivo vive na máquina do usuário; não vai para repositório nem
para plugin.

```
nome: <nome completo>
login: <login no SoftDesk>
usuario: <código do solicitante, de buscar_usuario>
atendente: <código no catálogo de atendentes, de listar_atendentes>
area: <código da área>
categoria: <código da categoria padrão>
servico: <código do serviço padrão>
prioridade: <código da prioridade padrão>
nivel_indisponibilidade: <código do impacto padrão>
```
